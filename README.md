# Quantitative Investment & Portfolio Dashboard

An interactive web application built with **Python** and **Streamlit** for comprehensive stock market analysis, portfolio risk management, and long-term financial planning.

## Key Features
- **Stock Analysis & Charts:** Historical price tracking and interactive visualizations across custom timeframes.
- **Correlation Matrix:** Asset correlation analysis to support portfolio diversification.
- **Monte Carlo Simulation:** Large-scale stochastic simulation (1,000,000 scenarios) modeling potential future portfolio paths.
- **Portfolio Risk & Strategy Comparison:** Evaluation of portfolio risk metrics, mathematical optimization, and side-by-side comparison of investment strategies.
- **Personal Finance & Tax Modules:** Built-in calculators for Polish IKE retirement accounts, capital gains tax reporting, and FIRE (Financial Independence, Retire Early) goal projections.
- **Data Persistence & Export:** Local JSON portfolio storage and export of analytical results.

## Tech Stack
- **Language:** Python
- **Web Framework:** Streamlit
- **Data & Quantitative Modeling:** NumPy, Pandas, SciPy (`scipy.optimize`)
- **Market Data:** yfinance
- **Visualization:** Plotly
